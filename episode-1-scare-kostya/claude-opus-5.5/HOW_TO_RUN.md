# HOW TO RUN

**Single command:**

```
start.bat
```

The launcher starts a local web server and opens the game in your browser. No internet required.

**Or manually:**

```
cd game
python -m http.server 8765
```

Then open **http://localhost:8765/index.html** in Chrome or Firefox.

---

**Requirements:**
- Python 3 (for the local server)
- Chrome or Firefox (not Edge in strict mode)
- Headphones recommended

**Controls:** Mouse only. Move the mouse to aim the flashlight.

**Permissions:** The game will ask for camera and microphone access. This is part of the experience — all processing is local and nothing is sent anywhere. The game works without them too.

**Duration:** About 5 minutes.
