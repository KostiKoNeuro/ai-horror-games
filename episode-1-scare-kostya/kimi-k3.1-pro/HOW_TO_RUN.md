# СМЕНА

## Запуск

Из этой папки выполните одну команду:

```bash
python start_game.py
```

Игра откроется в браузере автоматически. Установка зависимостей и подключение к интернету не требуются. На Windows также можно запустить `start_game.bat` двойным щелчком.

Для остановки локального сервера нажмите `Ctrl+C` в его окне.

## Управление

- **Мышь** — осмотр и взаимодействие.
- **1–4** — переключение камер.
- **Пробел** или **зажатая кнопка мыши** — удержание действия, когда оно указано на экране.
- **Esc** — назад / пауза.
- **M** — включить или выключить звук.
- **F** — полноэкранный режим.

Рекомендуются наушники. Запросы разрешений можно отклонить: игра останется полностью проходимой. Видео с камеры, если разрешение дано, обрабатывается только локально и никуда не отправляется.
